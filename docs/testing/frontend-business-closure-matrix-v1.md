# 前端业务闭环追踪矩阵 v1

## 范围

本矩阵覆盖当前管理端全部业务主模块，只评价前端领域模型、页面交互、Mock 数据流和自动测试。后端持久化、并发一致性、真实身份认证、外部税务及银行接口不属于本轮完成声明。

## 状态边界

- 主数据停用只阻止新业务，历史记录继续读取创建时快照。
- 已记账会计来源不能直接覆盖，改错进入冲销或后续期间调整。
- 税务申报和缴款可发生在会计期间结账后，不复用会计锁期作为写入门禁。
- 前端状态仅为当前会话演示，不宣称具备并发、持久化或生产审计能力。

## 尚未由前端解决的系统边界

- 登录身份、权限授权和操作人必须由后端会话提供；当前演示账号不可作为审计证据。
- 状态变更、编号分配、期间锁和跨模块提交需要后端事务与幂等控制。
- 银行回单、电子税务局申报表和回执需按真实文件契约接入并解析。
- 对象存储、病毒扫描、文件保全及长期归档需要后端和基础设施实现。
