# 税务会计计提与外部申报分期契约 V1

Date: 2026-07-15

Status: frontend_mock_implemented / backend_persistence_pending

## 1. 适用范围

本契约面向采用小企业会计准则、查账征收且以小规模纳税人身份申报的中小企业。目标是把同一税种的两类事实严格分开：

- 会计事实：税费属于哪个经营期间，应在该期间计提并记账。
- 外部办理事实：何时在电子税务局申报、缴款、取得回执。

外部办理通常晚于税款所属期，不得因此迫使企业等待次月申报后才结上月账。

## 2. 正向流程

```text
业务发生
-> 申报准备形成期末税额快照
-> 原期间生成税费计提凭证
-> 计提凭证记账并进入总账
-> 期间结账
-> 次月或法定申报期办理申报
-> 正式结果与原计提比较
-> 无差异则不新增会计凭证
-> 有差异则在实际申报月份生成调整凭证
-> 实际缴款形成收支流水和资金凭证
```

## 3. 税种边界

### 3.1 增值税及附加

- 增值税负债优先由销售、未开票收入等业务来源确认，税费计提凭证不得重复确认同一增值税。
- 城市维护建设税、教育费附加和地方教育附加根据期末申报准备快照计提。
- 正式申报与期末快照不一致时，差额进入申报月份调整凭证。
- 缴款只清偿应交税费负债，不再确认损益。

### 3.2 企业所得税

- 季度末根据当时已记账的本年累计利润和纳税调整形成季度计提。
- 次月确认正式季度申报时，季度三个月应已结账，申报只读取冻结快照。
- 正式应纳税额与季度末计提的差额进入申报月份。
- 年度汇算清缴不回写上年已结账期间，汇算差额进入实际办理月份。

### 3.3 印花税

- 根据已确认的应税合同、产权转移书据或营业账簿税源，在所属期间形成计提。
- 正式申报差异进入申报月份，不覆盖原计提。

### 3.4 个人所得税

- 工资薪金和自然人劳务在薪酬或劳务结算时已经形成代扣负债，不再生成重复税费计提凭证。
- 次月申报只核对代扣明细与正式申报结果；差异按更正来源进入开放期间处理。

## 4. 稳定凭证身份

- 原期间计提凭证：`voucher-tax-{taxMatterId}`。
- 正式申报差异凭证：`voucher-tax-{taxMatterId}-filing-v{declarationVersion}`。
- 原凭证会计期间取税款所属期，日期取所属期末日。
- 差异凭证优先进入实际申报日期所在月份；该月份已结账时，自动顺延至首个开放月份，凭证日期取顺延月份首日，真实申报日期保留在税务办理版本快照中。
- 每次正式申报或更正形成独立版本快照和稳定凭证候选；后续版本不得覆盖或移除前一版尚未记账的差异候选。
- 作废版本未记账的差异候选退出制单范围；差异凭证已经记账时不得直接作废申报，只能通过更正结果在后续开放期间调整。
- 外部申报、缴款或补回执不得改变原计提凭证 ID、期间、分录或来源快照。

## 5. 期间结账门禁

原期间结账检查：

- 税费计提依据是否完整。
- 应生成的税费计提凭证是否已经制单、记账。
- 总账、资金、社保公积金和报表检查是否通过。

原期间结账不检查：

- 次月申报是否完成。
- 税款是否已经缴纳。
- 申报或缴款回执是否已经上传。

已结账后允许继续申报和补充回执，但不得修改原期间会计事实。若实际申报月份也已结账，则差异继续进入下一个开放期间或走正式反结账流程，不能直接覆盖历史。

## 6. 前端状态边界

- `申报准备`：形成和确认期末计算快照，负责原期间计提依据。
- `税务办理`：登记申报、缴款、退税和回执，负责外部办理事实。
- `会计凭证`：分别展示原期间计提凭证和申报月份差异凭证。
- `期间结账`：只展示会计结果汇总，不重复展示税务办理明细。
- `收支流水`：承接实际缴退款资金事实。
- 税务事项的累计缴款、退税到账和完成状态由有效税费流水净额派生，不再作为独立可漂移金额维护。
- 复核前作废税费流水时，对应缴款或退税到账事实立即退出净额；已入账流水只能通过冲正，冲正复核入账后再反向恢复税务事项状态。
- 税费缴退流水只允许全额冲正；金额差异通过补差流水处理，不能用部分冲正破坏税种和会计科目分配。

当前状态仅为前端会话和 Mock 证据，不是正式税务申报、缴款、凭证记账或期间锁证据。

## 7. 前端展示口径

- 税务办理详情展示所属税期、当前申报版本和实际申报日期。
- 仅当申报版本实际形成差额凭证时展示差额入账期间；零差额版本不虚构入账结果。
- 历史申报按版本展示申报日期及对应差额凭证入账期间。
- 会计凭证详情使用结构化申报上下文展示所属税期、实际申报日期和申报版本，不从凭证号或摘要反向解析。
- 会计凭证统一使用“入账期间”，不使用含义较弱的“归属月份”。

## 8. 规则依据

- 更正申报按完整申报表重新申报；已缴款后只能更正、不能作废：[广东省电子税务局更正申报操作说明](https://guangdong.chinatax.gov.cn/gdsw/zhsw_fjcs_sfsbjjn/2024-03/06/content_9ea939f060a04b10a3a161955238c1f1.shtml)。
- 汇算清缴多缴税款通过退抵税流程处理，不直接覆盖原申报或原期间账务：[浙江省税务局汇算清缴结算多缴退抵税说明](https://zhejiang.chinatax.gov.cn/art/2026/4/8/art_26348_652772.html)。
- 同时存在应退税款和欠缴税款时，税务机关可先抵缴欠税再退还余额：[国家税务总局税款缴库退库工作规程](https://fgk.chinatax.gov.cn/zcfgk/c100011/c5195228/content.html)。

## 9. 验收场景

1. 6 月期末计提附加税，7 月申报且无差异：6 月计提凭证稳定，7 月不生成差异凭证。
2. 6 月期末计提企业所得税 5,000 元，7 月正式申报 5,300 元：6 月凭证保持 5,000 元，7 月生成 300 元调整凭证。
3. 6 月已经结账但尚未申报：6 月保持已结账，7 月税务办理仍可继续。
4. 正式申报表或申报结果回执晚到：只更新外部办理证据，不修改已记账原凭证。
5. 年度汇算产生补税：只在实际汇算月份生成调整，不回写上年度。
6. 个税申报完成：不额外生成一张重复代扣计提凭证。
7. 税款缴纳：资金凭证清偿对应应交税费，不重复进入税金及附加或所得税费用。
8. 申报日期所在月份已结账：真实申报日期不变，差异凭证自动进入首个开放月份。
9. 同一事项连续更正两次：第二版、第三版差异凭证各自保留，后续版本不得覆盖前版。
10. 作废未记账申报：该版差异候选退出；差异已记账时，作废入口被阻断并要求走更正。
11. 缴款流水复核前作废：税务事项恢复待缴款，不生成资金凭证，不保留有效缴款日期。
12. 已入账缴款流水全额冲正：冲正凭证抵消银行支出，税费负债重新形成未清余额，税务事项恢复待缴款。
13. 已入账退税到账流水全额冲正：冲正凭证抵消银行收入，税务事项恢复退税申请处理中，不再显示已到账。

## 10. 后端切换要求

后端接入时必须持久化申报准备快照、税费事项、申报版本、计提凭证、差异凭证和缴退款分配关系，并由服务端保证：

- 稳定 ID 和幂等生成。
- 已结账期间不可覆盖。
- 差异只能进入开放期间。
- 缴款分配与税费负债可勾稽。
- 金额精度、权限、审计和并发一致性。

在以上证据落地前，不得把本前端实现声明为正式记账、正式申报或生产级税务闭环。
