# 增值税申报准备硬切 V1（已废止）

本方案已由 [增值税申报准备硬切 V2](./vat-declaration-preparation-hardcut-v2.md) 完整替代，不再作为实现和验收依据。

废止原因：

- 旧方案从收款流水识别未开票收入，不符合当前以应税业务事实和纳税义务时点为主的口径。
- 旧方案允许财务自由选择计入或暂不计入，缺少系统默认纳入、例外原因和审计约束。
- 旧方案未覆盖后续开票冲抵前期未开票收入的防重复申报关系。

当前有效口径：

1. 系统识别本期纳税义务已发生、尚未开票且尚未申报的业务事项。
2. 税务依据完整的候选默认纳入本期申报测算。
3. 财务仅核对系统结果；排除事项必须选择原因，未说明原因时阻断确认。
4. 确认后冻结申报准备快照；后续开票按原业务关系冲抵前期未开票收入。
