# 财务类目前端硬切验收 v1

## 范围

本轮仅处理前端财务类目主数据、消费契约与历史快照，不新增审批流，不涉及后端持久化或生产数据迁移。

## 业务边界

- 一级类目定义收支方向、经营统计归集和报表边界。
- 二级类目定义业务来源、适用对象、收付方式、凭证要求及实际入账科目角色。
- 新业务事实读取当前启用的类目配置。
- 已形成的应收应付和流水读取自身保存的类目快照，不被后续改名、停用或科目调整改写。
- 内置类目名称保持稳定；有子类目的一级类目不得直接改变收支方向。

## 门禁

- 文档门禁：本文件明确类目层级、历史快照和消费端边界。
- 自动门禁：`corepack pnpm typecheck`、`corepack pnpm test:web`、`corepack pnpm build:web`、`corepack pnpm ai-native:check`。
- 证据门禁：FC-01 至 FC-11 必须至少有领域测试、类型检查或页面约束证据之一；跨模块金额、快照或凭证结果必须有领域测试。

## 后端接入边界

后端接入时应使用稳定的一级/二级类目 ID 与科目角色编码持久化；业务事实必须保存不可变类目快照。不得重新以类目中文名称作为唯一外键或在查询时用当前配置重算历史科目。
