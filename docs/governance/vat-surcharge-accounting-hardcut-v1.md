# 增值税与附加税会计口径硬切 V1

Date: 2026-07-12

Status: frontend_mock_implemented / backend_persistence_pending

## 1. 目标

本轮把小规模纳税人的增值税及附加税从“一个税额、一条税费凭证”硬切为可核对的分项模型，消除增值税重复计入损益、附加税负债混记以及缴款凭证无法清账的问题。

范围包括：

- 申报准备保存期末税额分项快照，税务办理读取该快照并登记正式申报结果。
- 增值税、城市维护建设税、教育费附加、地方教育附加使用独立负债科目。
- 期末申报准备只计提附加税，不重复计提已经由业务来源确认的增值税；次月税务办理只登记申报差异。
- 合并缴款流水保留四项负债清偿分配，资金凭证逐项冲减负债。
- 税额来源不一致或缴款分配不完整时，凭证进入 `需处理`，不能记账。

本轮不包含后端持久化、电子税务局接口、正式凭证号、服务端期间锁或生产迁移。

## 2. 会计边界

### 2.1 业务发生

销售或应收来源凭证确认收入与增值税负债。增值税是价外税，不进入税金及附加费用。

示例：

```text
借：应收账款 / 银行存款
贷：主营业务收入
贷：应交税费 - 应交增值税
```

### 2.2 期末计提

期末申报准备结果与来源已确认增值税一致后，只计提城市维护建设税、教育费附加和地方教育附加：

```text
借：税金及附加
贷：应交税费 - 应交城市维护建设税
贷：应交税费 - 教育费附加
贷：应交税费 - 地方教育附加
```

### 2.3 实际缴款

税款真实支付并形成待复核流水。复核、对账满足资金凭证条件后，按缴款分配逐项冲减负债：

```text
借：应交税费 - 应交增值税
借：应交税费 - 应交城市维护建设税
借：应交税费 - 教育费附加
借：应交税费 - 地方教育附加
贷：银行存款
```

## 3. 前端合同

`FinanceVatTaxSettlementSnapshot` 是申报准备向期末税费凭证提供、并由税务办理复核的期间结果快照：

- `declaredVatAmount`：申报确认的增值税。
- `sourceRecognizedVatAmount`：业务来源凭证已经确认的增值税负债。
- `surcharge`：三项附加税的减征前、减征额和减征后金额。
- `totalPayableAmount`：增值税与三项附加税合计。

`FinanceTaxPaymentAllocation[]` 是合并缴款流水的负债清偿分配：

- 每项必须携带税种、会计科目和金额。
- 分配合计必须等于该笔缴款流水金额。
- 多次缴款时，新流水只携带尚未登记的剩余分配。
- 已存在的关联缴款缺少分配时，不继续猜测生成后续流水。

## 4. 科目口径

| 科目 | 用途 |
| --- | --- |
| `2221.01 应交增值税` | 业务来源确认及实际缴纳的增值税 |
| `2221.04 应交城市维护建设税` | 城市维护建设税计提与缴纳 |
| `2221.06 教育费附加` | 教育费附加计提与缴纳 |
| `2221.07 地方教育附加` | 地方教育附加计提与缴纳 |
| `5403 税金及附加` | 三项附加税的损益归集 |

## 5. 阻断规则

- 申报准备缺少增值税结算快照：期末附加税凭证为 `需处理`。
- 申报增值税与来源已确认增值税不一致：附加税凭证为 `需处理`。
- 次月正式申报与原快照存在差异：在申报月份生成差异调整凭证，不改写原期间附加税凭证。
- 增值税及附加合并缴款缺少分项分配或分配合计不等于流水金额：资金凭证为 `需处理`。
- 部分缴款若无法从既有分配推导剩余清偿金额，不自动生成流水。
- 零附加税且无异常时，不生成金额为零的附加税计提凭证。

## 6. Mock 验收样例

2026 Q1 样例固定为：

| 项目 | 金额 |
| --- | ---: |
| 应缴增值税 | 440.10 元 |
| 城市维护建设税 | 15.41 元 |
| 教育费附加 | 6.60 元 |
| 地方教育附加 | 4.40 元 |
| 附加税合计 | 26.41 元 |
| 本次应缴合计 | 466.51 元 |

验收要求：

- 申报准备与税务办理展示以上相同分项，并明确区分原期间计提与申报月份差异。
- 附加税计提凭证金额为 26.41 元，且不包含 `2221.01`。
- 缴款资金凭证借方包含四个负债科目，贷方为银行存款。
- 缺少分配和增值税来源不一致的测试均必须阻断记账。

## 7. 后端切换要求

后端接入时必须以不可变申报结果快照和缴款分配明细替代前端 Mock；税务结果、来源增值税负债、缴款流水和会计凭证之间使用稳定 ID 关联。服务端负责金额精度、并发、审计、期间锁和记账幂等，前端不得自行回算或覆盖已记账事实。
