# 增值税申报准备硬切 V2

日期：2026-07-11

## 目标

面向当前湖北武汉小规模纳税人、按季申报口径，申报准备必须以应税业务事实为主来源。发票用于确认开票销售额，收支流水仅用于资金核对，不再反向决定未开票收入。

## 数据边界

- 已确认应收事项代表当前系统中的应税业务事实。
- 应收事项的税务口径提供价税合计、不含税金额、税额、业务分类和适用口径。
- 发票与应收事项通过发票业务分摊关联。
- 已确认应收事项在所属期内未被发票覆盖的部分，自动形成未开票应税事项。
- 后续发票关联到前期已按未开票收入申报的原应收事项时，在后续开票期间自动冲抵，避免重复申报。
- 银行流水、收款状态和结清状态不决定增值税纳税义务是否发生。

## 前端流程

1. 系统汇总本季度销项蓝票、红票和已确认应收事项。
2. 系统按发票分摊计算应收事项未开票部分。
3. 税务口径完整的未开票部分由系统默认纳入申报；税务口径缺失时保持待核实并阻断确认。
4. 财务人员核对系统结果，不自由挑选申报事项。取消纳入时必须选择“尚未发生纳税义务、已开票、已在前期申报、重复事项或不征税事项”之一，未说明原因时继续阻断。
5. 无销项蓝票属于合法来源状态，可继续零申报或仅未开票收入申报。
6. 系统生成专票、其他发票及未开票、货物及劳务、服务/不动产/无形资产、税率分项和附加税减征等申报栏次。
7. 用户确认系统结果和例外说明；确认后冻结申报准备快照并进入税务办理。

## 移除内容

- 从已入账收款流水中选择未开票收入。
- 无原因、无审计记录的“本期暂不计入”操作。
- 发票直接关联未开票流水的新增入口。
- 申报准备项中的内部核对风险和资金复核提示。
- 主列表中的来源数据、调整项和最近更新列。

## 验收标准

- 未收款但已确认的应收事项可进入未开票应税事项。
- 税务口径完整的候选默认勾选并计入，不要求财务逐条手工选择。
- 取消纳入后必须填写排除原因；未填写时申报准备不可确认。
- 有效排除不进入税额测算和确认快照，并保留操作记录。
- 预收款或普通收款流水不会单独生成未开票收入。
- 无蓝票期间不阻断零申报。
- 后续发票关联原应收事项后自动冲抵前期未开票收入。
- 红票未关联原蓝票时仍阻断申报口径确认。
- 专票销售额低于免税限额时仍按票面口径计税。
- 已进入税务办理的历史结果保持快照，不被后续本地来源变化静默覆盖。
